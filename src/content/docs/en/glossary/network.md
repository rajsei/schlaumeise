## Networks

A **network** is a **group of at least two devices** that exchange data. Networks can be wired (LAN) or wireless (Wi-Fi). They enable the sharing of resources such as files, printers, and internet access.

## Wi-Fi (Wireless Local Area Network)

A **Wi-Fi network** is **a wireless local area network** that connects devices within a limited area (e.g., an apartment, office, or café). It enables communication and data exchange without cables. A Wi-Fi can exist with or without internet access.

### Example of a Wi-Fi network

A computer and a printer are connected to **the same Wi-Fi**. This allows the computer to send print jobs without the need for a cable. The network enables data exchange between the devices. If the Wi-Fi is also connected to the internet, both devices can use online services. Without internet access, the connection is limited to the local network.

## Hotspot

A **hotspot** is **a device or a location** that **provides Wi-Fi** so that other devices can connect.

**With Internet access:** Connected devices can access the internet.

**Without Internet access:** Devices can only communicate locally (e.g., exchange files or use printers), but cannot go online.

### Example of a Hotspot

A **smartphone acts as a hotspot**, providing Wi-Fi that other devices can use. A **tablet connects** to it and uses the smartphone’s cellular network to access the internet. This keeps the tablet online even when no other Wi-Fi network is available. If the smartphone itself does not have internet access, the connection works only locally, e.g., for file sharing between devices.

## Distinctions

**Network** is the umbrella term for connected devices.

**Wi-Fi** is a wireless form of a local network.

**Hotspot** is a device or location that provides a Wi-Fi network, usually with a focus on internet access.
