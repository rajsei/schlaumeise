Which birds sing around you, and at what time of day?
Smartfinch Pi turns a Raspberry Pi and a USB microphone into a bird station that listens around the clock.
The AI BirdNET identifies the bird species directly on the Pi. The station needs neither internet nor a cloud service for this.
You see the results in the browser on your phone, tablet or computer.

You don't need a console to set it up: you write a ready-made image to the SD card, plug in the Pi and set it up in your browser through its own Wi-Fi hotspot.

## What will you build?

In the end, you will have a bird station with:

- a Raspberry Pi with a USB microphone that records bird songs,
- BirdNET, which identifies the species directly on the device,
- a web interface with the latest detections, audio recordings, spectrograms and statistics,
- a species filter that only keeps birds expected at your location in the current season,
- its own Wi-Fi hotspot, so you can reach the station even when there is no Wi-Fi nearby.

## Smartfinch Pi or BirdNET-Pi?

Both run BirdNET on a Raspberry Pi.
The project [The Listening Birdhouse](../project01/) is based on BirdNET-Pi, a community project that you install and set up from the console.
Smartfinch Pi is designed to be set up without a console: a ready-made SD image, a setup wizard in the browser and a hotspot that starts by itself when no known Wi-Fi is in range.
The interface is available in English and German.

## Data and license

Recordings and detections stay on the Pi. There is no user account and no cloud service.
