## Checklist: What do I need?

<input type="checkbox" class="checkbox checkbox-primary"/> A **Raspberry Pi**

    - **Raspberry Pi 5** approx. €55-140 (2-16 GB RAM)
    - **Raspberry 4B** approx. €40-80 (1-8 GB RAM)
    - **Raspberry Pi 3B** approx. €40
    - **Raspberry Pi** W2 approx. €20
      - The Raspberry Pi Zero 2 W is the least powerful model among the supported devices.
      If you choose this model, you should invest in a **high-performance SD card**, since a large part of the system load is shifted onto the card. In addition, not all BirdNET-Pi functions can be run reliably on the Zero 2 W.
      To avoid crashes or limited responsiveness, it is advisable to disable features such as live audio in BirdNET-Pi.

<input type="checkbox" class="checkbox checkbox-primary"/> **SD card** at least 8 GB

    - For the Raspberry Pi 5, Raspberry Pi 4B, and Raspberry Pi 3B+, a normal SD card is usually sufficient – for example a Class 10 or UHS-I card with good read and write speeds. However, if you are using a Raspberry Pi Zero 2 W, we recommend a high-quality SD card.
      With this model, a larger part of the system load is offloaded onto the SD card, so the performance and durability of the card are especially important here.

<input type="checkbox" class="checkbox checkbox-primary"/> possibly an **adapter** for a microSD card to your computer

<input type="checkbox" class="checkbox checkbox-primary"/> **Power supply** for your Raspberry Pi

<input type="checkbox" class="checkbox checkbox-primary"/> **USB microphone** or **USB sound card and AUX microphone**


<input type="checkbox" class="checkbox checkbox-primary"/> For the Raspberry Pi Zero W2, a **microUSB - OTG adapter** is additionally required

<input type="checkbox" class="checkbox checkbox-primary"/> If you don't want to set up the Pi via SSH, i.e. using your computer, or for troubleshooting, the following may be useful: a **Mini HDMI to HDMI adapter** to connect the Pi to a screen. A **USB keyboard** – pay attention to which and how many USB ports your Pi provides.
